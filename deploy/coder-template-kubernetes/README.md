# VCL 工作区模板

一句话:申请一台容器化的开发机,CPU、内存、GPU、磁盘都按申请值做硬限制,浏览器里直接打开 VS Code。

## 你会得到什么

- **资源**:CPU 8/16/32 核,内存 16/32/48 GB,GPU 可选 1 到 4 张 RTX 3080 Ti(也可以不使用显卡),系统盘 100 到 500 GB。
- **磁盘是硬配额**:容器里 `df` 看到的就是申请值,写超会被内核直接拦下。
- **镜像**:Ubuntu 24.04(默认)或 Ubuntu 24.04 + CUDA 12.8。GPU 工作区建议选 CUDA 版。
- **开发环境**:浏览器版 VS Code,工作区页面 Apps 里打开;不预装插件,插件与设置都随 `/home/coder` 保留。
- **身份**:容器内统一是 `coder` 用户(uid 1000),`sudo` 免密。

## 申请与使用

1. 网页上 `Workspaces` → `Create Workspace`,选本模板,按顺序选参数。加减号按钮会显示当前可选范围,到边界时给出提示。
2. 命令行也可以创建,并且不受界面上的范围限制:
   `coder create <名字> --template kubernetes --parameter cpu=8 --parameter memory=16 --parameter gpu_model=none --parameter gpu_count=1 --parameter image=... --parameter home_disk_size=100 --parameter hdd_volume=`
3. 申请页顶部的容量条显示集群当前还能分配多少(每 10 秒自动刷新,也可以手动刷新)。提交后会再校验一次,资源不够会直接拒绝并说明原因,不会创建任何东西。
4. 需要改参数时,进工作区页面改 `Parameters`。改磁盘大小或数据卷会让工作区重启一次,里面的数据不受影响。
5. 停止、启动工作区都会保留数据;删除工作区会清空系统盘和 `/home/coder`,但独立申请的数据卷不受影响。

## 数据卷(冷数据)

- 在 `Volumes` 页面申请,单卷 100 到 1000 GB,每人合计 1000 GB(这是界面上的限制)。
- 创建工作区时在「数据卷」里选自己的卷,容器内固定挂到 `/mnt/data`。
- 同一个卷可以同时挂到多个工作区,并发写入的冲突需要自己避免;删除卷要求没有运行中的工作区在用它,并且要二次确认。
- 页面上支持分片上传,断点续传、失败自动重试;遇到同名文件会让你选择覆盖或保留两者;上传前会检查卷内剩余空间,不够会直接拒绝。
- 数据卷里的数据不会因为工作区被删除而消失。

## 使用建议

- 集群是单节点、1GbE 网络,没有 InfiniBand,适合单机多卡;工作区之间网络互通。
- HDD 数据盘是 4 块磁盘线性拼接、没有冗余,只适合放冷数据,也不能当备份用。
- `/tmp` 不持久化;需要保留的数据请放在 `/home/coder` 或数据卷里。
- 需要长期保存的大文件建议先上传到数据卷,再在工作区里使用。
